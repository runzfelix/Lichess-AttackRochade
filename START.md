# 🚀 Projekt-Startbefehle

### 1. Lichess 256 (16×16 Schachbrett) starten
Wechselt in den Ordner `bigBoard`, beendet alte Server und startet die Website auf Port 8000:
```bash
cd /workspaces/codespaces-blank/bigBoard && pkill -f "http.server" ; python3 -m http.server 8000
```

---

### 2. Dein erstes Schach-Projekt (`epic_chess.py`) starten
Wechselt in den Hauptordner und startet dein Python-Skript:
```bash
cd /workspaces/codespaces-blank && pkill -f "http.server" ; python3 epic_chess.py
```

---

### 💡 Nützliche Terminal-Kurzbefehle
* **Laufendes Programm stoppen:** `Ctrl + C`
* **Aktuellen Ordner anzeigen:** `pwd`

---
